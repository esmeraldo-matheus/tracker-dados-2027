# Missão Dados 2027 — Tracker de Estudos

Painel gamificado offline-first para acompanhar a trilha prática de **SQL, BI (Power BI / Looker Studio) e Python para Dados**, com foco em construção de portfólio em 10 semanas.

## Recursos
- Contagem regressiva dinâmica até `01/02/2027` e relógio em tempo real com countdown de fim do dia
- Personagem e quarto em pixel art 2D com evolução visual independente em 4 áreas (Código/SQL, Leitura, Dados/BI e Constância)
- Timer Pomodoro integrado (`25m`, `15m Dia Caótico`, `5m Pausa`, `10m Leitura`)
- Sistema de XP, níveis, *streak*, cronograma adaptativo estilo Coursera e Estacionamento de Pensamentos
- Base SQL normalizada (`pratica_sql_semana1.sql`) e template Python de AED reprodutível (`aed_reprodutivel_template.py`)
- Sincronização opcional entre navegadores/dispositivos via **GitHub Gist Secreto** (nenhum dado pessoal fica salvo no repositório)

## Privacidade
Todo o progresso individual fica armazenado apenas no navegador (`localStorage`) e, se ativado pelo usuário, em um **GitHub Gist Secreto** na sua própria conta usando um token com escopo mínimo `gist`.
